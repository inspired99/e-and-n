# E&N

Дневник полезных привычек на двоих, Елисея и Нели. Спорт и чтение считаются по неделям, готовка дома и питание по месяцам. Бриллианты недели и месяца, уровень, достижения, «вместе!», образы персонажей. Статический сайт без сборки и без авторизации, синхронизация через Firebase Realtime Database. Основа взята из fixgaz.

Сайт: `https://inspired99.github.io/e-and-n/`. Пример с выдуманными данными: `?demo`.

## Запуск у себя

```bash
python3 -m http.server 8766 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8766`. Пример: `http://127.0.0.1:8766/?demo`. Нужный экран открывается ссылкой: `?demo&me=0&open=stats`, где `open` это `stats`, `food`, `rules`, `log`, `look`, `menu` или `goal`; `&view=month` включает месяц, `&step=bun` раскрывает продукт в листе «отметить».

## Тесты

```bash
node --test tests/*.test.js
```

Зависимостей нет, нужен Node 20 или новее. Правила (`tests/rules.test.js`) проверяют неделю, месяц, перенос октября, уровень, позы и «вместе»; дымовой тест (`tests/ui.test.js`) рисует каждый экран и лист на примере.

## Правила коротко

- **Неделя** (пн-вс): спорт и чтение, прогресс `min(1, сделано / цель)`, по среднему 3 бриллианта от 100%, 2 от 66%, 1 от 33%.
- **Месяц**: три бриллианта, минус один за каждый продукт сверх лимита и минус один, если готовки меньше цели. Не ниже нуля.
- **Уровень**: растет за недели подряд с бриллиантами, падает за плохие недели и за плохой месяц, от `-lvlMax` до `lvlMax`.
- **Поза**: каждый день по Москве персонаж спит до своей первой отметки; кашляет после `coughDays` дней без спорта; в форме от `fitSport` тренировок за неделю.
- «Сегодня» у всего приложения московское.
- Все числа меняются в меню. Лимит «не считаем» хранится в базе как `-1`: Firebase стирает `null`.

## Данные

`rooms/<ключ>` в Firebase:

- `settings`: `players`, `start`, `createdDay`, `weekly.<sport|read>.goal.{p0,p1}`, `monthly.cook.goal.{p0,p1}`, `food.<продукт>.{p0,p1}`, `carry.<YYYY-MM>.{p0,p1}.<вид>` (что было до приложения), `looks.{p0,p1}`, пороги и цены, `resetDay`.
- `events/<id>`: `{ id, who, kind, day, at, n? }`. Журнал только пополняется, удаление это пометка `del`.

Ключи localStorage начинаются с `en:` и `en.`: fixgaz живет на том же адресе `inspired99.github.io`, и хранилище у сайтов общее.

## Синхронизация

База та же, что у fixgaz (`config.js`, `DB_URL`), у E&N своя комната. Ключ общего дневника зашит в `config.js` (`ROOM`): любой телефон и любой значок на домашнем экране открывают этот дневник без ссылок. Ключ виден всем, кто знает адрес сайта. Если на устройстве раньше был другой дневник, приложение предложит перенести из него отметки.

Правила базы (уже стоят, общие с fixgaz):

```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "rooms": { "$room": { ".read": "$room.length >= 20", ".write": "$room.length >= 20" } }
  }
}
```

## Выкладка

Сайт собирает `tools/build-site.sh <папка>`: копирует только файлы сайта (без тестов, инструментов и исходников картинок) и пишет `version.json` и `js/build.js` с хешем и временем коммита. По `version.json` открытое приложение узнает о новой версии и обновляется само; в приложении с домашнего экрана то же делает свайп вниз, в меню есть «обновить приложение».

- **GitHub Pages**: в настройках Pages источник GitHub Actions. Workflow `.github/workflows/pages.yml` на каждый пуш в `main` прогоняет тесты и вызывает `sh tools/build-site.sh _site`. Пуш по SSH.
- **Cloudflare Pages** (если понадобится): команда сборки `sh tools/build-site.sh _site`, папка `_site`.

## Как устроено

| Файл | Что в нем |
|---|---|
| `js/rules.js` | правила: неделя, месяц, перенос, уровень, позы, «вместе», достижения, московский день. Чистые функции |
| `js/model.js` | модель для разметки из журнала и состояния экрана |
| `js/store.js` | снимок с сервера плюс очередь неотправленных записей |
| `js/sync.js` | адаптеры: локальный, Firebase, память для примера |
| `js/update.js` | обновление: перечитать файлы мимо кеша, проверка новой версии |
| `js/ui.js` | разметка экранов и листов |
| `js/main.js` | запуск, состояние экрана, действия |
| `js/sprites.js` | значки 12 на 12 и наклейки сетками, персонажи картинками |
| `js/copy.js` | тексты и даты |
| `js/demo.js` | выдуманный журнал для `?demo` |
| `css/tokens.css` | цвета, шрифты, шаг сетки |

## Картинки

Образы нарисованы владельцем: листы 2 на 2 на пурпурном фоне в `assets/src/looks/<кто>-<образ>.png`, позы слева направо и сверху вниз: обычная, в форме, кашель с облачком, спит. Нарезка всех образов:

```bash
node tools/sprites.mjs looks
```

Один новый лист: `node tools/sprites.mjs look <лист> <кто>-<образ>`, например `node tools/sprites.mjs look assets/src/looks/elisey-winter.png elisey-winter`, затем добавить образ в `LOOKS` (`js/sprites.js`) и подпись в `LOOK` (`js/copy.js`). Нужны `ffmpeg` и `cwebp`. Картинки выходят в `assets/sprites/<кто>-<образ>-<поза>.webp`, поза `idle`, `fit`, `cough`, `sleep`.

Комната, стена и декор пока из fixgaz (`assets/src/scene.webp`, `wall.webp`, `props.png`). Иконка временная, собрана из спрайтов. Промпты на общую квартиру, иконку и зимний образ Елисея: `assets/PROMPTS.md`.
