# E&N

Дневник полезных привычек на двоих, Елисея и Нели. Спорт и чтение считаются по неделям, готовка дома и питание по месяцам. Цели недели и месяца, лимиты еды, достижения, образы персонажей и поцелуи друг другу. Уровней, бриллиантов и «вместе» нет: владелец не хочет соревнования между двумя. Статический сайт без сборки и без авторизации, синхронизация через Firebase Realtime Database. Основа взята из fixgaz.

Сайт: `https://inspired99.github.io/e-and-n/`. Пример с выдуманными данными: `?demo`.

## Запуск у себя

```bash
python3 -m http.server 8766 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8766`. Пример: `http://127.0.0.1:8766/?demo`. Нужный экран открывается ссылкой: `?demo&me=0&open=stats`, где `open` это `stats`, `food`, `rules`, `log`, `look`, `menu` или `goal`; `&view=month` включает месяц, `&step=bun` раскрывает продукт в листе «отметить».

## Тесты

```bash
node --test tests/*.test.js
```

Зависимостей нет, нужен Node 20 или новее. Правила (`tests/rules.test.js`) проверяют неделю, месяц, перенос октября, позы и поцелуи; дымовой тест (`tests/ui.test.js`) рисует каждый экран и лист на примере.

## Правила коротко

- **Неделя** (пн-вс): спорт и чтение против цели на неделю, набранная цель зеленым и «цель недели!». Оценок за неделю нет.
- **Месяц**: готовка против цели на месяц, еда против лимита у каждого. Сверх лимита красным с крестиком, без штрафов и оценок.
- **Поцелуй**: кнопка «поцелуй» в комнате пишет `kisses/{id}`. У второго на экране всплывают сердца с подписью «Елисей шлет поцелуй», один раз на устройство (`en:kissSeen:*`), только поцелуи моложе трех дней, несколько сразу как «×N».
- **Поза**: каждый день по Москве персонаж спит до своей первой отметки; кашляет после `coughDays` дней без спорта; в форме от `fitSport` тренировок за неделю.
- «Сегодня» у всего приложения московское.
- **Сезон и время суток в комнате** по Москве: зима 15.11 - 14.03, весна 15.03 - 31.05, лето июнь - август, осень 01.09 - 14.11. Часы дня, вечера и ночи свои у каждого сезона (зима: день 9-16, вечер 16-21, ночь 21-9; осень 8-17, 17-21, 21-8; весна 7-19, 19-22, 22-7; лето 6-20, 20-23, 23-6). Комната перерисовывается сама, когда наступает вечер или ночь. В меню можно выбрать свое, это запоминается только на телефоне (`en:season`, `en:time`).
- **Снег** зимой вечером и ночью идет за панорамным окном, только за стеклами.
- **Итог месяца**: в первые 7 дней месяца один раз на телефоне (`en:story:*`) тому, кто зашел, показывается теплый лист про прошлый месяц: спорт и чтение, готовка, еда в лимитах, 2-3 строки похвалы по правилам и «ты молодец». Без сравнения со вторым. Итог любого прошлого месяца открывается из «итогов». Ничего не пишется в базу.
- Все числа меняются в меню. Лимит «не считаем» хранится в базе как `-1`: Firebase стирает `null`.

## Данные

`rooms/<ключ>` в Firebase:

- `settings`: `players`, `start`, `createdDay`, `weekly.<sport|read>.goal.{p0,p1}`, `monthly.cook.goal.{p0,p1}`, `food.<продукт>.{p0,p1}`, `carry.<YYYY-MM>.{p0,p1}.<вид>` (что было до приложения), `looks.{p0,p1}`, пороги позы. Старые ключи уровня и бриллиантов (`gem1..3`, `lvl*`, `resetDay`, `overCost`, `cookCost`) приложение просто не читает.
- `events/<id>`: `{ id, who, kind, day, at, n? }`. Журнал только пополняется, удаление это пометка `del`.
- `kisses/<id>`: `{ id, from, to, at }`, так же только пополняется, убрать можно пометкой `del`.

Ключи localStorage начинаются с `en:` и `en.`: fixgaz живет на том же адресе `inspired99.github.io`, и хранилище у сайтов общее.

## Синхронизация

База та же, что у fixgaz (`config.js`, `DB_URL`), у E&N своя комната. Ключ общего дневника зашит в `config.js` (`ROOM`): любой телефон и любой значок на домашнем экране открывают этот дневник без ссылок. Ключ виден всем, кто знает адрес сайта. Если на устройстве раньше был другой дневник, приложение предложит перенести из него отметки.

Правила базы (уже стоят, общие с fixgaz):

```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "rooms": { "$room": { ".read": "$room.length >= 20", ".write": "$room.length >= 20" } }
  }
}
```

## Выкладка

Сайт собирает `tools/build-site.sh <папка>`: копирует только файлы сайта (без тестов, инструментов и исходников картинок) и пишет `version.json` и `js/build.js` с хешем и временем коммита. По `version.json` открытое приложение узнает о новой версии и обновляется само; в приложении с домашнего экрана то же делает свайп вниз, в меню есть «обновить приложение».

- **GitHub Pages**: в настройках Pages источник GitHub Actions. Workflow `.github/workflows/pages.yml` на каждый пуш в `main` прогоняет тесты и вызывает `sh tools/build-site.sh _site`. Пуш по SSH.
- **Cloudflare Pages** (если понадобится): команда сборки `sh tools/build-site.sh _site`, папка `_site`.

## Как устроено

| Файл | Что в нем |
|---|---|
| `js/rules.js` | правила: неделя, месяц, перенос, позы, поцелуи, достижения, московский день. Чистые функции |
| `js/model.js` | модель для разметки из журнала и состояния экрана |
| `js/store.js` | снимок с сервера плюс очередь неотправленных записей |
| `js/sync.js` | адаптеры: локальный, Firebase, память для примера |
| `js/update.js` | обновление: перечитать файлы мимо кеша, проверка новой версии |
| `js/ui.js` | разметка экранов и листов |
| `js/main.js` | запуск, состояние экрана, действия |
| `js/sprites.js` | значки 12 на 12 и наклейки сетками, персонажи картинками |
| `js/copy.js` | тексты и даты |
| `js/demo.js` | выдуманный журнал для `?demo` |
| `css/tokens.css` | цвета, шрифты, шаг сетки |

## Картинки

Образы нарисованы владельцем: листы 2 на 2 на пурпурном фоне в `assets/src/looks/<кто>-<образ>.png`, позы слева направо и сверху вниз: обычная, в форме, кашель с облачком, спит. Нарезка всех образов:

```bash
node tools/sprites.mjs looks
```

Один новый лист: `node tools/sprites.mjs look <лист> <кто>-<образ>`, например `node tools/sprites.mjs look assets/src/looks/elisey-winter.png elisey-winter`, затем добавить образ в `LOOKS` (`js/sprites.js`) и подпись в `LOOK` (`js/copy.js`). Нужны `ffmpeg` и `cwebp`. Картинки выходят в `assets/sprites/<кто>-<образ>-<поза>.webp`, поза `idle`, `fit`, `cough`, `sleep`.

Комната нарисована по сезону и времени суток: `assets/src/rooms/<сезон>-<время>.png` (сезон `winter`, `spring`, `summer`, `autumn`, время `day`, `evening`, `night`). Сборка в `assets/bg/room-<сезон>-<время>.webp` и список готовых картинок в `js/room-art.js`:

```bash
node tools/rooms.mjs
```

Пока нарисован только осенний вечер. Чего нет, то приложение берет ближайшей картинкой (сначала то же время суток, потом соседний сезон) и кладет поверх свет: ночью синий, днем светлее и холоднее, лампы ночью теплые. Окно для снега измерено по этой картинке (`.pane` в `css/app.css`): если в новых картинках окно сдвинется, поправить проценты там.

Декор из fixgaz (`assets/src/props.png`). Иконка временная, собрана из спрайтов. Промпты на общую квартиру, иконку и зимний образ Елисея: `assets/PROMPTS.md`.
